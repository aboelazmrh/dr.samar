# استمارة متابعة تغذية — د. سمر صلاح أبو العين

صفحة عربية RTL بخط Tajawal، وتصميم أخضر متجاوب، وشخصية بروكلي كرتونية، وأصوات قابلة للإيقاف.
27 سؤالًا إجباريًا على 5 خطوات: البيانات الأساسية، القياسات، الروتين والصحة، الأهداف والتفضيلات، والعادات الغذائية. التالي يتحقق من إجابات الخطوة، والسابق والتعديل يحتفظان بالإجابات في الذاكرة فقط.

## التشغيل
```sh
cd /workspace/dr.samar
python3 server.py
```

## المحتوى
الأسئلة نُقلت من صور المستخدم؛ خيارات الجبن نُقلت من الصورة الإضافية: قريش، رومي، ملح خفيف، فيتا، موتزريلا، وأخرى. كل الأسئلة مطلوبة، ويمكن كتابة «لا يوجد» عند عدم انطباق السؤال.
أيقونة الدكتورة مثبتة في بداية الصفحة من نسخة مهيأة للصورة المرفقة باستخدام أداة الصور، وتُعرض دائرية بإطار أخضر. الملف: `assets/doctor.png`.
رقم واتساب المؤكد هو `201031233719`. تُحفظ الإجابات على الخادم وتُعرض في لوحة محمية `/admin`. إعداد إشعار واتساب التلقائي والنشر موضح في `DEPLOYMENT.md`؛ الربط الفعلي ما زال مطلوبًا.

## التحقق
```sh
node --check app.js
node --check form-config.js
```
تم اختبار المتصفح على عرض الجوال وسطح المكتب، والحقول الإجبارية، والخطوات الخمس، والرجوع والتعديل، ورسالة واتساب المجمعة، وإيقاف الصوت ببيانات تجريبية، دون إرسال أي رسالة.

راجع `DEPLOYMENT.md` للنشر والتخزين الدائم وبيانات الدخول وربط واتساب.
